Админка сайта

Два редактора с одинаковыми полями. Оба меняют одни и те же файлы в папке content/, поэтому то, что вы правите в одном, видно в другом. Откройте оба и сравните.

Админка A: Sveltia CMS

Проект с 2023 года, лицензия MIT.

Открыть A

Вход на опубликованном сайте
по персональному токену GitHub, без отдельного сервера.
Работа с локальными файлами
кнопка «Work with Local Repository», только Chrome, Edge или Brave. Запуск decap-server не нужен.

Админка B: Decap CMS

Проект с 2015 года (бывший Netlify CMS), лицензия MIT.

Открыть B

Вход на опубликованном сайте
через GitHub и отдельный сервис авторизации (OAuth), который пока не поднят.
Работа с локальными файлами
в Терминале запущен npx decap-server, браузер любой.

Страницы A и B читают общий файл config.yml. Правки на опубликованном сайте попадают в репозиторий GitHub и после пересборки видны на сайте.
